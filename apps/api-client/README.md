# api-client

The typed client for `contracts/openapi.json`. `src/generated/schema.ts` is generated by `just gen`
(openapi-typescript); never edit it. `src/index.ts` turns a path and method into a typed fetch:
path parameters are percent-encoded, the bearer token goes in the Authorization header (never a
URL, including for the payout stream, read with fetch), and a refusal is an `ApiError` naming its
rule. `src/format.ts` escapes HTML, fills copy templates and shows money in minor units; it never
computes an amount.

```ts
const api = createClient({ baseUrl: "", token: () => token });
const quote = await api.post("/me/quotes", { body: { plan_id: "essential" } });
await api.post("/me/quotes/{quote_id}/accept", { path: { quote_id: quote.offer.offer_id } });
```
